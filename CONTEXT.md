# slopchat

slopchat — самостоятельный, развивающий собственное поведение Lisp-агент
с непрерывной памятью одного пользовательского чата.

## Language

**Lisp-агент**:
Исполнитель пользовательских задач, способный изменять собственное поведение
посредством кода. Его поведение принадлежит slopchat.
_Avoid_: агент Codex, адаптер модели

**Модель Ouro**:
Способ развития агента из минимальной исходной оболочки: агент сам создаёт
продолжение своего поведения и может впоследствии его изменять.
_Avoid_: готовый неизменяемый агентный цикл

**Адаптер модели**:
Граница доступа к языковой модели, передающая контекст и возвращающая ответы
и запросы инструментов для обработки Lisp-агентом.
_Avoid_: исполнитель задач, память, Lisp-агент

**Память slopchat**:
Постоянная история чата вместе с иерархией резюме и представлением,
через которое агент получает предыдущий контекст.
_Avoid_: история сессии Codex, встроенная память Codex

**Задание суммаризации**:
Ограниченная работа модели по сжатию сообщения или объединению двух резюме
с сохранением смысла исходных данных.
_Avoid_: пользовательский ход, самостоятельный агент

**Пользовательский ход**:
Выполнение задачи пользователя, включающее ответы модели, действия агента
и уточнения, поступающие во время работы.
_Avoid_: весь чат, один вызов модели

**Чат**:
Непрерывная пользовательская история и её память, идентичность которой
определяется выбранным каталогом.
_Avoid_: пользовательский ход, техническая сессия модели

### Предлагаемая модель нескольких тредов

**Проект**:
Пространство самостоятельных бесед Ouro, использующих одну постоянную память.
_Avoid_: отдельный тред, сессия модели

**Тред**:
Самостоятельная пользовательская беседа внутри проекта, имеющая собственные
ходы и исполнителя Ouro.
_Avoid_: временный тред Codex, пользовательский ход

**Общая память проекта**:
Постоянная история событий тредов и иерархия их резюме, доступная исполнителям
проекта.
_Avoid_: история текущего выполнения, состояние вкладки

**Снимок памяти**:
Согласованное представление общей памяти с определённой границей видимости
событий.
_Avoid_: вся память проекта, история текущего хода
