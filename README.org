#+title: SlopChat

SlopChat is a headless Emacs Lisp agent with durable chat memory. It combines
Ouro's self-written agent loop with Victor Taelin's hierarchical memory design.
Codex app-server provides model access through an existing ChatGPT subscription;
the Lisp agent owns execution and memory.

A chat directory identifies one conversation. Its history and memory survive
server restarts; the agent bootstraps its Lisp loop again on restart. Interrupted
tasks do not resume automatically.

* Run

Requirements: Emacs 30+, Codex CLI authenticated with a ChatGPT account, Linux
=flock= and =truncate=, and Bun for the terminal client. Check authentication with
=codex login status=. An API key is not required.

From the repository root, start the server:

#+begin_src sh
emacs --batch -Q -L lisp -l slopchat-cli \
  --eval '(slopchat-serve ".chats/main")'
#+end_src

In another terminal, from the same repository root:

#+begin_src sh
bun install --cwd ui
./scripts/chat-tui
#+end_src

Enter sends; Ctrl+Enter inserts a newline (Ctrl+J is the terminal compatibility
fallback). Sending while the agent works steers its current turn. Ctrl+C closes
the client; the server keeps running.

For another chat, start its server with that directory and run
=./scripts/chat-tui /absolute/chat/directory=. Only one server can own a chat.

Optional Python 3 client:

#+begin_src sh
python3 scripts/slopchat.py .chats/main 'Hello!'
python3 scripts/slopchat.py --help
#+end_src

* Update the running terminal view

Publish presentation changes from the repository root:

#+begin_src sh
bun ui/src/publish.ts
#+end_src

Publication runs typecheck, tests and headless smoke checks. It is active only
when the running client's status row acknowledges it and
=ui/.revisions/activation.json= records the published file and that client's PID
with status =committed=. Source edits alone do not activate. Host, dependency,
native-renderer and state-schema changes require a client restart.
